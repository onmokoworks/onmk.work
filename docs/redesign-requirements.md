# onmk.work リデザイン要件（ドラフト v0）

> ブランチ: `redesign` / 起点: タイムライン実装済みの状態
> ステータス: 🟡 要件整理中（このファイルを叩き台に詰める）

## 0. 方向性（ビジョン）
- **白ベース**でもっと **ポップ**に
- ミニマルすぎる今のトーンから、遊びのある見た目へ（twemojiアイコンに寄せる）
- ページ構成は **もっとシンプル**に

## 1. 決まっていること
- [x] 背景は白ベース
- [x] 左上にロゴ
- [x] 自己紹介の**上**に「動くグラデーションのバー」→ **細いラインが横に流れる**タイプ
- [x] 各ページをシンプルに
- [x] トップのアクティビティ・タイムラインは継続
- [x] **スコープ: 全ページ一括**（works / tools / blog / about / 各詳細）
- [x] **ポップの色: カラフル（多色グラデ）** を主役に
- [x] **テーマ: 白一本化**（Light固定、Dark / Flashlight は廃止）

## 2. デザイン決定

### 色（多色グラデ・おまかせ提案）
- シグネチャーグラデ: **青 → 紫 → ピンク → オレンジ**（ビビッド）
  - 例: `#4f8cff → #8b5cf6 → #ec4899 → #fb923c`
- 用途: 動くバー / ホバー / アクセント / リンク下線 等に展開
- ※モックで見て調整

### 動くグラデーションバー
- タイプ: **細いライン**（数px）が横に流れる
- 配置: ヘッダー直下〜自己紹介の上（配置幅はモックで確定）

### ロゴ（左上）
- **ユーザーがSVGを後で支給**（今はプレースホルダ）
- ナビ（works / tools / blog / about）はポップに再配置

## 3. これから決めること（残）
- 各ページの「シンプルに」= 具体的に削る/まとめる要素（モック後に詰める）
- タイポ（現行 ABCDiatypeEdu を活かす / 見出しを大きく太く 等）
- 角丸・余白・ホバー等のトーン（モックで確定）

## 3. 既存資産（引き継ぐもの）
- タイムライン（works / GitHub repos[allowlist] / releases / blog）
- twemojiアイコン（🎬/📝/🚀 + repoはGitHubマーク）※ポップ化に合わせ見直し予定（work=🎬は映像寄りすぎ）
- microCMS（works / tools / blog / log）、GitHubキャッシュ層
- テーマ機能（Light / Dark / Flashlight）
